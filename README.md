A bespoke WordPress theme developed for **Axis Medical**, specializing in medical infrastructure, specialized healthcare construction, and hospital equipment solutions.

This theme combines a custom lightweight PHP framework with modern JavaScript interactivity and responsive HTML/CSS designs, complemented by flexible Elementor page builder integrations.

---

## 🌟 Key Features & Tech Highlights

### 🐘 Custom PHP Architecture
* **Custom Theme Functions & Hooks:** Modular `functions.php` structure tailored specifically for performance and clean action/filter execution.
* **Custom Queries & Templating:** Native PHP templating for key pages, landing sections, and dynamic custom post types.
* **Security & Sanitization:** Strict input validation, nonces, and output escaping applied across custom data transactions.

### ⚡ JavaScript (DOM Manipulation & AJAX)
* **Asynchronous Data Handling:** Built-in JS AJAX handling for smooth dynamic content loading without full page reloads.
* **Vanilla JS DOM Manipulation:** Clean client-side interactions, custom modal windows, filtering systems, and UI navigation triggers.

### 🎨 Custom HTML5 & CSS3 Design
* **Bespoke UI/UX:** Tailored layouts designed specifically for corporate healthcare presentation.
* **Responsive Layouts:** Mobile-first, fluid layout grids designed with custom CSS.
* **Optimized Rendering:** Minimal external UI dependency overhead for quick paint times and high Google Lighthouse performance scores.

### 🧩 Hybrid Elementor Integration
* **Flexible Page Building:** Custom page templates configured to allow content managers to tweak select sections using Elementor while preserving strict code-level layout boundaries.
